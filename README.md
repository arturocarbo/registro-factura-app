# 📄 Registro Factura - App de Gastos para Vendedores

Aplicación web móvil (PWA Ready) para el escaneo e ingesta rápida de comprobantes de gastos en terreno para vendedores.

## 🚀 Características
- 📸 **Escaneo inteligente:** Utiliza la API de Google Gemini Flash 3.0 para extraer automáticamente datos clave (Fecha, Monto total, Impuestos, Razón social/Comercio, Número de factura y Categoría).
- ✏️ **Revisión y edición:** Permite validar los datos extraídos antes de confirmar el registro.
- ✉️ **Envío por correo formateado para SAP:** Formatea el borrador del correo con los datos limpios y un payload JSON estructurado listo para la carga a SAP.
- 📊 **Dashboard e historial:** Registro de gastos por estado y exportación a archivos CSV compatibles con SAP.

## 📲 Instalación en iPhone
1. Abre el enlace desplegado en **Safari**.
2. Presiona el botón **Compartir** (cuadrado con la flecha hacia arriba).
3. Selecciona **"Agregar a inicio"**.
