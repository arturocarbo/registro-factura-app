# 📄 Registro Factura - App para Vendedores (SAP Ready)

Aplicación web progresiva (PWA) para que los vendedores escaneen y registren sus facturas de gastos desde el móvil usando la API de Gemini.

## 🚀 Características
- Escaneo con IA mediante **Google Gemini Flash 3.0**.
- Extracción automática de fecha, comercio, número de factura, impuestos y monto.
- Formateo directo para correo electrónico y JSON para carga automática en SAP.
- Exportación en CSV compatible con sistemas contables.

## 📱 Instalación en iPhone
1. Abre la URL en **Safari**.
2. Presiona el botón **Compartir** (cuadrado con flecha hacia arriba).
3. Selecciona **"Agregar a inicio"**.
